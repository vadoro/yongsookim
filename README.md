# 김용수 · Yongsoo Kim — Curriculum Vitæ

한림대학교 영어영문학과/디지털인문예술전공 김용수 교수의 인터랙티브 이력서 웹사이트입니다.
문예지의 한 호(號)처럼 꾸몄습니다. 마스트헤드와 표지, 목차, 그리고 I–VI 장으로 이어지는 구성입니다.

## 기능

- **표지**: 이름 조판 애니메이션, 라캉의 보로메오 매듭(Fig. 1), 연구 분야 칩(누르면 해당 주제의 연구로 이동)
- **목차 · 한눈에 보기**: 논문·저서·역서·강연·발표 수를 데이터에서 직접 계산해 보여 줍니다
- **II. 연보**: 학력·경력·학회 활동을 하나의 시간 축(1987–현재)에 놓은 타임라인
- **IV. 연구 성과**: 연도별 논문·저서 그림(블록 하나 = 성과 한 편, 색 = 주제). 막대를 누르면 연도, 범례를 누르면 주제로 거르고, 검색어는 목록에서 강조됩니다
- **V. 초청 강연**: 유형별 필터(기조 강연 / 주제 발표 / 특강·강연), 이전 강연 접기
- **VI. 학술 발표**: 도시·날짜를 앞세운 데이트라인 형식
- 한국어/영어 전환(KO · EN), 밤에 읽기(다크 모드), 읽기 진행 표시줄, 러닝 헤드
- 인쇄하면 장식 없이 깔끔한 종이 이력서로 출력됩니다

빌드 과정이 없는 정적 사이트입니다(HTML · CSS · JavaScript).

## 내용 고치기

모든 이력 데이터는 **`assets/js/data.js`** 한 파일에 있습니다. 항목을 추가하거나 고치면 목록, 그림, 숫자가 모두 함께 바뀝니다.

- 제목 안의 `*별표*`는 이탤릭으로 표시됩니다(작품명·학술지명).
- `themes`: `dh`(디지털인문학), `theory`(정신분석·비평이론), `amlit`(미국문학), `film`(영화). 첫 번째 태그가 그림의 색을 정합니다.
- 기간은 `"2024.09"`처럼 적고, 현재 진행 중이면 `end: ""`로 둡니다.

### 사진 넣기

1. 사진을 `assets/img/profile.jpg`로 저장합니다(세로 4:5 비율 권장).
2. `assets/js/data.js`의 `photo: ""`를 `photo: "assets/img/profile.jpg"`로 바꿉니다.

사진이 없으면 표지에 보로메오 매듭 그림이 들어갑니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## GitHub Pages로 공개하기

1. 저장소의 **Settings → Pages**로 갑니다.
2. **Build and deployment → Source**를 *Deploy from a branch*로, 브랜치를 `main` / `/ (root)`로 정하고 저장합니다.
3. 잠시 뒤 `https://vadoro.github.io/yongsookim/`에서 열립니다.

## 파일 구조

```
index.html            페이지 구조(표지, 목차, 프로필, 각 장의 틀)
assets/css/style.css  디자인 토큰, 레이아웃, 다크 모드, 인쇄 스타일
assets/js/data.js     이력 데이터
assets/js/main.js     렌더링과 인터랙션(타임라인, 그림, 필터, 검색, 언어/테마 전환)
assets/img/           사진 등 이미지
```
