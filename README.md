# 김용수 · Yongsoo Kim — Network

한림대학교 영어영문학과/디지털인문예술전공 김용수 교수의 인터랙티브 이력서 웹사이트, **네트워크 성좌** 버전입니다.
`main` 브랜치의 문예지 에디토리얼 버전과 같은 데이터를 쓰고, 디자인과 인터랙션만 다릅니다.

## 기능

- **표지 연결망**: 논문·저서·강연·학술 발표 제목 74개에서 키워드 30개를 찾아 그린 공기어 연결망입니다. 원의 크기는 키워드가 나온 제목 수, 선의 굵기는 한 제목에 함께 나온 횟수, 색은 주제(디지털인문학 / 정신분석·비평이론 / 미국문학 / 영화)입니다.
  - 원에 마우스를 올리면 이웃 키워드가 밝아지고, 누르면 왼쪽 패널에 함께 나온 키워드와 관련 제목이 나타납니다.
  - 원을 끌어서 옮길 수 있습니다.
  - "연구 성과에서 보기"를 누르면 그 키워드가 들어간 논문·저서만 목록에 남고, 제목에서 키워드가 강조됩니다.
- **소개**: 사진, 국문/영문 소개, 박사학위 논문, 연구 분야(누르면 해당 주제로 필터)
- **연보**: 학력·경력·학회 활동 타임라인. 2000년 이후가 잘 보이도록 그 이전은 축소해 표시합니다
- **연구 성과**: 연도별 논문·저서 그림(블록 하나 = 한 편)과 주제·유형·검색·키워드 필터
- **강연·발표**: 초청 강연(유형별 필터, 접기)과 학술 발표를 탭으로 나눴습니다
- 한국어/영어 전환, 읽기 진행 표시줄, 현재 섹션 표시, 인쇄용 보기
- **DH Tutorials** (`tutorials.html`): [DH 튜토리얼](https://dhtutorials.vercel.app/) 사이트로 이어지는 페이지입니다. 튜토리얼 목록은 그 사이트의 `assets/catalog.js`를 직접 불러와 그리므로, 새 튜토리얼을 올리면 이 페이지에도 자동으로 나타납니다. 불러오지 못하면 `assets/js/tutorials.js`에 적어 둔 목록을 보여 줍니다.

빌드 과정이 없는 정적 사이트입니다(HTML · CSS · JavaScript, 외부 라이브러리 없음).

## 내용 고치기

모든 이력 데이터는 **`assets/js/data.js`** 한 파일에 있습니다.

- 제목 안의 `*별표*`는 이탤릭으로 표시됩니다.
- `themes`: `dh`, `theory`, `amlit`, `film`. 첫 번째 태그가 연도별 그림의 색을 정합니다.
- 기간은 `"2024.09"`처럼 적고, 현재 진행 중이면 `end: ""`로 둡니다.
- **`keywords`**: 표지 연결망의 키워드 사전입니다. `match`에 적은 문자열 중 하나가 제목에 들어 있으면 그 키워드가 나온 것으로 셉니다. 키워드를 추가·삭제하거나 `match`를 고치면 연결망이 다시 계산됩니다. `group`은 노드 색입니다.

표지 사진은 `assets/img/profile.jpg`(800×1000)입니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## GitHub Pages로 공개하기

GitHub Pages는 브랜치 하나만 공개할 수 있습니다. 이 버전을 공개하려면 **Settings → Pages**에서 브랜치를 `network-constellation` / `(root)`로 바꾸거나, 이 브랜치를 `main`에 병합하세요.

## 파일 구조

```
index.html            첫 화면
assets/css/style.css  디자인 토큰, 레이아웃, 인쇄 스타일
assets/js/data.js     이력 데이터와 키워드 사전
assets/js/main.js     연결망 레이아웃(포스 시뮬레이션)과 모든 인터랙션
tutorials.html        DH Tutorials 페이지
assets/js/tutorials.js  DH Tutorials 페이지의 목록과 언어 전환
assets/img/           사진
```
