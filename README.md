# 김용수 · Yongsoo Kim — Network

한림대학교 영어영문학과/디지털인문예술전공 김용수 교수의 인터랙티브 이력서 웹사이트, **네트워크 성좌** 버전입니다.
`main` 브랜치의 문예지 에디토리얼 버전과 같은 데이터를 쓰고, 디자인과 인터랙션만 다릅니다.

## 기능

- **표지 연결망**: 논문·저서·강연·학술 발표 제목(지금은 75개)에서 키워드 30개를 찾아 그린 공기어 연결망입니다. 원의 크기는 키워드가 나온 제목 수, 선의 굵기는 한 제목에 함께 나온 횟수, 색은 주제(디지털인문학 / 정신분석·비평이론 / 미국문학 / 영화)입니다.
  - 원에 마우스를 올리면 이웃 키워드가 밝아지고, 누르면 왼쪽 패널에 함께 나온 키워드와 관련 제목이 나타납니다.
  - 원을 끌어서 옮길 수 있습니다.
  - "연구 성과에서 보기"를 누르면 그 키워드가 들어간 논문·저서만 목록에 남고, 제목에서 키워드가 강조됩니다.
- **소개**: 사진, 국문/영문 소개, 박사학위 논문, 연구 분야(누르면 해당 주제로 필터)
- **연보**: 학력·경력·학회 활동 타임라인. 2000년 이후가 잘 보이도록 그 이전은 축소해 표시합니다
- **연구 성과**: 연도별 논문·저서 그림(블록 하나 = 한 편)과 주제·유형·검색·키워드 필터
- **강연·발표**: 초청 강연(유형별 필터, 접기)과 학술 발표를 탭으로 나눴습니다
- 한국어/영어 전환, 읽기 진행 표시줄, 현재 섹션 표시, 인쇄용 보기
- 모든 페이지 오른쪽 아래의 '맨 위로' 단추: 한 화면쯤 내려가면 나타납니다(`assets/js/to-top.js`, 영어 튜토리얼 · DH 튜토리얼 사이트와 같은 동작).
- 위쪽 메뉴: 화면이 1190px 이하로 좁아지면 첫 화면 섹션 링크를 숨기고 페이지 링크(발표 자료 · DH Tutorials · English Tutorials · 영어영문학과 · 디지털인문예술전공)만 둡니다(1275px 이하에서는 이름 옆 영문 이름도 숨김). 메뉴 링크를 더하면 이 두 너비를 다시 재야 합니다(`style.css`의 주석 참고). 휴대폰처럼 그래도 넘치면 메뉴를 옆으로 밀어 볼 수 있고, 지금 보는 페이지의 링크가 보이도록 맞춰 둡니다.
- **발표 자료** (`slides.html`): 강연·발표 슬라이드 목록입니다. 목록은 `assets/js/data.js`의 `slides`에서 그립니다(아래 '발표 자료 추가하기'). 지금은 'Vibe Learning'과 '한림대 영어영문학과 전공설명회'(날짜 없이 계속 고쳐 쓰는 자료라 날짜가 있는 자료 아래) 두 개입니다.
- **DH Tutorials** (`tutorials.html`): [DH 튜토리얼](https://dhtutorials.vercel.app/) 사이트로 이어지는 페이지입니다. 튜토리얼 목록은 그 사이트의 `assets/catalog.js`를 직접 불러와 그리므로, 새 튜토리얼을 올리면 이 페이지에도 자동으로 나타납니다. 불러오지 못하면 `assets/js/tutorials.js`에 적어 둔 목록(지금은 다섯 편)을 보여 줍니다. 방문자가 튜토리얼 사이트로 오도록 카드에는 '인터랙티브로 보기'만 두고, MP4 내려받기 링크는 넣지 않습니다(카탈로그의 `video` 항목은 쓰지 않음).
- **English Tutorials** (`english.html`): [영어 튜토리얼](https://engtutorials.vercel.app/) 사이트로 이어지는 페이지입니다. DH Tutorials 페이지와 같은 방식으로 그 사이트의 `assets/catalog.js`를 직접 불러오고, 영역(`tracks`: 토익, 상황별 영어 회화)별로 묶어 보여 줍니다. 새 튜토리얼이나 새 영역이 올라오면 자동으로 나타나고, 불러오지 못하면 `assets/js/english.js`에 적어 둔 목록(지금은 스무 편)을 보여 줍니다. 새 영역의 영어 이름은 `english.js`의 `TRACK_EN`에 적습니다(없으면 한국어 이름).
- **영어영문학과** (`dell.html`): [학과 홈페이지](https://dell.hallym.ac.kr/dell/index.do)와 [전공설명회 자료](https://claude.ai/artifact/UyRg2A7dZEoq34br8cYPK6)로 이어지는 페이지입니다. 첫 화면 소개, 네 트랙(모듈 · 진로), 4년 로드맵, 배움의 현장(영어 튜토리얼 · 해외 답사 · 교환학생 · 학과 생활)은 전공설명회 자료의 내용을 옮긴 것으로, 페이지에 직접 적혀 있습니다. 설문 비율 · 취업률 · 협정대학 수처럼 자주 바뀌는 숫자는 넣지 않고 전공설명회 자료로 보냅니다. 설명회의 트랙 구성이나 교과가 크게 바뀌면 이 페이지도 함께 고칩니다.
- **디지털인문예술전공** (`dah.html`): [디지털인문예술전공 웹사이트](https://dah-hallym.vercel.app/)로 이어지는 페이지입니다. 첫 화면의 한 줄 소개('미래를 디자인하는 창의적 리더 양성')와 소개 문단, 아래 '전공 트랙'의 세 트랙(디자인 · AI · 엔터컬쳐) 소개는 전공 웹사이트의 문구입니다(영문은 옮긴 것). 오른쪽의 '전공과 함께한 기록'(2017년 전공 신설, 2024.09–2026.08 주임교수, 2022년 주제 발표 두 편)은 페이지에 직접 적혀 있으니, 기록이 늘면 `dah.html`에서 고칩니다.

빌드 과정이 없는 정적 사이트입니다(HTML · CSS · JavaScript, 외부 라이브러리 없음).

## 내용 고치기

모든 이력 데이터는 **`assets/js/data.js`** 한 파일에 있습니다.

- 제목 안의 `*별표*`는 이탤릭으로 표시됩니다.
- `themes`: `dh`, `theory`, `amlit`, `film`. 첫 번째 태그가 연도별 그림의 색을 정합니다.
- 기간은 `"2024.09"`처럼 적고, 현재 진행 중이면 `end: ""`로 둡니다.
- 강연(`lectures`)에 `slides: "슬라이드 주소"`를 적으면 그 항목에 '슬라이드' 링크가 붙습니다. 같은 슬라이드로 다른 행사에서 다시 발표했다면 `lectures`에 새 줄을 하나 더 적으면 됩니다(발표 자료 페이지의 카드에도 '발표한 자리'로 나타납니다).
- **`keywords`**: 표지 연결망의 키워드 사전입니다. `match`에 적은 문자열 중 하나가 제목에 들어 있으면 그 키워드가 나온 것으로 셉니다. 키워드를 추가·삭제하거나 `match`를 고치면 연결망이 다시 계산됩니다. `group`은 노드 색입니다.

표지 사진은 `assets/img/profile.jpg`(800×1000)입니다.

### 발표 자료 추가하기

`assets/js/data.js` 맨 아래 `slides` 배열에 항목 하나를 추가하면 발표 자료 페이지에 카드가 생깁니다. 연도(`year`)와 날짜(`date`)가 최근인 것부터 위에 놓입니다.

```js
{
  title: "발표 제목",
  subtitle: "부제",
  kind: "Keynote",             // 표지 위 작은 글씨
  year: 2027,
  date: "2027.03.15",          // 없으면 ""
  slides: 20,                  // 슬라이드 수
  url: "https://claude.ai/artifact/...",
  summary: { ko: "한두 문장 소개", en: "One or two sentences" },
  outline: ["1부 제목", "2부 제목"],
  cover: { bg: "#15171C", glow: "#2C3A1B", ink: "#EDEAE3", accent: "#C8F169", muted: "#AEB4BF", prompt: "표지 맨 위 한 줄" }
}
```

`lectures`에 이 자료와 같은 슬라이드 주소(`slides`)로 적은 발표가 있으면, 카드에 그 날짜와 장소가 '발표한 자리'로 최근 순으로 모이고, 가장 최근 발표 날짜가 카드의 날짜가 됩니다(이때 `date`는 적지 않아도 됩니다). 예를 들어 'Vibe Learning'은 2026.10.27(한림대)과 2026.11.09(성균관대) 두 번 발표했습니다.

날짜 없이 계속 고쳐 쓰는 자료(예: 전공설명회)는 `year`·`date` 대신 `ongoing: true`를 적습니다. 날짜 자리에 '계속 업데이트'가 나오고, 날짜가 있는 자료들 아래에 놓입니다. 아티팩트를 고쳐도 주소는 그대로이므로 링크는 바꿀 필요가 없고, 내용이 크게 바뀌면 카드의 소개(`summary`)·핵심 항목(`points`)·목차(`outline`)·슬라이드 수만 맞춰 주면 됩니다.

선택 항목:

- `points`: 색 막대가 붙은 짧은 핵심 목록. `{ label, items: [{ color, name, tag, note }] }`
- `cover.title`·`cover.sub`: 표지에만 쓸 제목, `cover.grad: [색1, 색2]`: 표지 제목 그라데이션, `cover.lines: [색, …]`: 표지 오른쪽 위의 색 선(최대 4개)
- 글자 항목(`kind`, `outline` 한 줄, `points`의 `name`·`tag`·`note`·`label`)은 `"글자"`로도, `{ ko: "…", en: "…" }`로도 적을 수 있습니다.

Claude 아티팩트로 만든 슬라이드는 공유 설정을 **링크가 있는 누구나 볼 수 있게** 해 두어야 방문자가 열 수 있습니다.

## 공개 주소

`main` 브랜치는 Vercel 프로젝트 `yongsookim`에 연결되어 있어, `main`에 push하면 https://yongsookim.vercel.app 에 자동으로 배포됩니다. 다른 브랜치를 push하면 미리보기 주소가 따로 생깁니다.

## 파일 구조

```
index.html            첫 화면
assets/css/style.css  디자인 토큰, 레이아웃, 인쇄 스타일
assets/js/data.js     이력 데이터와 키워드 사전
assets/js/main.js     연결망 레이아웃(포스 시뮬레이션)과 모든 인터랙션
slides.html           발표 자료 페이지
assets/js/slides.js   발표 자료 목록
tutorials.html        DH Tutorials 페이지
assets/js/tutorials.js  DH Tutorials 페이지의 목록
english.html          English Tutorials 페이지
assets/js/english.js  English Tutorials 페이지의 목록
dell.html             영어영문학과 페이지
dah.html              디지털인문예술전공 페이지
assets/js/page.js     하위 페이지 공통(언어 전환, 별 배경, 진행 표시줄)
assets/js/to-top.js   모든 페이지의 '맨 위로' 단추
assets/img/           사진
```
